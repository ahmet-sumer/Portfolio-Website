Nmap Beyond the Basics

📅 Apr 01, 2026 ⏱️ 8 min read 🏷️ Nmap, Enumeration, NSE, Firewall Evasion

Everyone knows nmap -sV. This note covers the things that actually matter once you move past the basics — scan timing, NSE scripts, firewall evasion, and output formatting that feeds directly into your pentest workflow.

Host Discovery

Default nmap sends ICMP echo, TCP SYN to 443, TCP ACK to 80, and ICMP timestamp. On internal networks this is fine. On external targets behind firewalls, you need to get creative.

Flag What it does When to use
-sn Ping sweep only, no port scan Quick host enumeration on large subnets
-Pn Skip host discovery, treat all as up Target blocks ICMP / you already know it's alive
-PS22,80,443 TCP SYN ping on specific ports Firewalled hosts that only respond on known open ports
-PA TCP ACK ping Stateless firewalls that drop SYN but pass ACK

Scan Types That Matter

Scan Flag Use case
TCP Connect -sT No raw socket access (non-root), proxychains
SYN Stealth -sS Default for root — fast, less logged
UDP -sU Don't forget SNMP (161), TFTP (69), DNS (53)
Version -sV Always. Combine with --version-intensity 5 for stubborn services

NSE — The Real Power

The Nmap Scripting Engine turns nmap from a port scanner into an actual enumeration framework. Key categories:

bash 
# Run default scripts (safe + useful)
nmap -sC -sV TARGET

# Run specific category
nmap --script=vuln TARGET

# Run specific script
nmap --script=smb-enum-shares TARGET

# Multiple scripts
nmap --script=http-title,http-headers,http-methods TARGET

# Find available scripts
ls /usr/share/nmap/scripts/ | grep smb

Scripts I actually use on every engagement:

  • smb-enum-shares, smb-enum-users — AD environments, always
  • http-enum — directory/file bruteforce via nmap
  • vuln — quick CVE check, good for low-hanging fruit
  • banner — when -sV doesn't grab enough

Firewall / IDS Evasion

When default scans get blocked or you need to stay quiet:

bash 
# Fragment packets
nmap -f TARGET

# Decoy scan — blend with fake source IPs
nmap -D RND:5 TARGET

# Source port manipulation (DNS = 53, often whitelisted)
nmap --source-port 53 TARGET

# Slow timing to avoid rate-based detection
nmap -T2 TARGET

# Combine for maximum evasion
nmap -f --source-port 53 -T2 -Pn TARGET
Timing Name Note
-T0 Paranoid 5 min between probes — IDS evasion only
-T1 Sneaky 15 sec between probes
-T2 Polite Good balance for quiet scans
-T4 Aggressive CTF / lab default — fast and loud

Output — Feed Your Workflow

bash 
# All formats at once (normal + XML + grepable)
nmap -oA scans/initial TARGET

# Grepable output — pipe to other tools
nmap -oG - TARGET | grep open

# XML for report generation
nmap -oX scan.xml TARGET
xsltproc scan.xml -o report.html

Always use -oA. The XML output feeds into tools like searchsploit and custom parsers. The grepable format is perfect for one-liners when you need to chain results.

My Go-To Commands

bash 
# Initial recon — fast, wide
nmap -sS -sV -sC -T4 -oA scans/initial TARGET

# Full port scan — don't miss anything
nmap -p- -sS -T4 -oA scans/allports TARGET

# Targeted deep scan on found ports
nmap -p 22,80,445,8080 -sV -sC -A -oA scans/targeted TARGET

# UDP top 20 — often forgotten, often rewarding
nmap -sU --top-ports 20 -oA scans/udp TARGET
